# Experiment 07: Admissible State Space

## Theoretical Claim

Viability is a region from which continuation remains possible, not a single optimum.

## Computational Model

This crate implements the smallest dependency-free Rust model needed to expose the distinction under examination. Run it with:

```bash
cargo run -p exp07-admissible-state-space
```
